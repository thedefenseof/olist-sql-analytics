# Olist E-Commerce Analytics Project

Комплексный аналитический проект на датасете бразильского маркетплейса Olist (~100 тыс. заказов, 2016–2018).

## Структура проекта

- **power-bi/** — интерактивный дашборд (6 страниц): обзор бизнеса, доставка и отзывы, продавцы и товары, RFM-сегментация клиентов, выводы и рекомендации
- **sql/** — SQL-запросы (PostgreSQL), дублирующие часть аналитики из дашборда: оконные функции, многотабличные джоины, CTE
- **python/** — скрипт загрузки CSV-датасета в PostgreSQL (pandas + SQLAlchemy)

## Ключевые инсайты

- Опоздание доставки свыше 7 дней снижает оценку заказа с 4.25 до 1.7 из 5
- Только 3.12% клиентов совершают повторную покупку — низкий retention
- VIP-сегмент (3.6% клиентов) формирует 6.94% выручки
- Топ-10 продавцов дают лишь ~11% выручки при минимальном % опозданий — здоровая диверсификация

## Стек

Power BI (Power Query, DAX) · PostgreSQL · SQL (оконные функции, CTE, join) · Python (pandas, SQLAlchemy)
